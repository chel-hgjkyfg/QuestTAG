# КвестТаг — сайт и серверный консультант GigaChat

Сайт публикуется на GitHub Pages, серверный API консультанта запускается отдельно.

## Что реализовано

- Адаптивная главная страница и более понятные для родителей названия разделов.
- Каталог активностей, готовые пакеты и прайс по категориям.
- Конструктор праздника: несколько активностей в одной смете, число гостей, аренда комнаты, дополнительные услуги, удаление позиций и общий итог.
- Кнопка переноса всей собранной программы в форму заявки.
- Увеличенный блок ИИ-консультанта на базе GigaChat с контекстом прайса и историей диалога.
- Сервер FastAPI: OAuth-токен GigaChat получается на сервере; секрет не передаётся браузеру.
- Форма заявки пока остаётся демонстрационной: сохраняет черновик в localStorage и не отправляет его администратору.

## Публикация фронтенда на GitHub Pages

1. Откройте Settings → Pages.
2. В Build and deployment выберите Deploy from a branch.
3. Выберите ветку main и папку /(root), сохраните.
4. Адрес сайта: https://chel-hgjkyfg.github.io/QuestTAG/

## Развёртывание GigaChat API на Render

1. Войдите в Render и создайте новый Blueprint, выбрав этот GitHub-репозиторий.
2. Render прочитает `render.yaml` и создаст веб-сервис `questtag-gigachat-api`.
3. В настройках Environment добавьте `GIGACHAT_AUTH_KEY`. Значение — Authorization Key из кабинета GigaChat API (не Client ID отдельно и не Client Secret отдельно). Не публикуйте его в GitHub, config.js или сообщениях.
4. Если в кабинете для вашего проекта выдан другой scope, замените `GIGACHAT_SCOPE` на точное значение из кабинета. По умолчанию используется `GIGACHAT_API_PERS`.
5. Дождитесь успешного Deploy. Проверьте адрес `https://ИМЯ-СЕРВИСА.onrender.com/health`: ожидается JSON с `"ok": true` и `"configured": true`.
6. Откройте в репозитории `config.js` и укажите публичный адрес сервера:
   `window.QUESTTAG_API_URL = "https://ИМЯ-СЕРВИСА.onrender.com";`
7. Сохраните изменение. После публикации GitHub Pages чат начнёт обращаться к GigaChat.

Если адрес сервера изменится, обновите только `config.js`. В нём допускается только публичный URL backend — никаких ключей и токенов.

## Локальный запуск backend

Python 3.11+:

```bash
pip install -r requirements.txt
export GIGACHAT_AUTH_KEY="ваш Authorization Key"
export GIGACHAT_SCOPE="GIGACHAT_API_PERS"
uvicorn main:app --reload --port 8000
```

Затем задайте в `config.js`:

```js
window.QUESTTAG_API_URL = "http://localhost:8000";
```

## Правила расчёта конструктора

- Игровые активности и картинг умножаются на количество гостей по опубликованному прайсу.
- Для лазертага, Among Us и пряток в темноте учитывается минимум 5 участников.
- Квест включает до 10 гостей; каждый дополнительный участник — 600 ₽.
- Дополнительные услуги считаются фиксированной суммой; для ведущего и SECRET BOX выбран тариф по числу гостей.
- Аренда комнаты на 1–2 часа считается по часовому тарифу; 3 часа — по опубликованному трёхчасовому тарифу. Для времени свыше 3 часов к трёхчасовому тарифу прибавляется каждый дополнительный час по цене часа. Это предварительная оценка, которую администратор должен подтвердить.
- Для выбора комнаты калькулятор показывает предупреждение, если число гостей не соответствует диапазону в прайсе.

## Ограничения и безопасность

- GitHub Pages — только статический frontend. GigaChat вызывается сервером FastAPI.
- Authorization Key хранится только в Environment Variables на Render. Не добавляйте его в репозиторий.
- Не отключайте TLS-проверку сертификата GigaChat.
- В текущем backend есть системная инструкция и встроенный прайс, но нет RAG/векторной базы и нет подключения к CRM.
- Форма заявки пока сохраняет черновик в браузере; реальная отправка, база заявок, Telegram и панель администратора не реализованы.
- Для реального сбора персональных данных нужно подключить защищённый backend для заявок, ограничить доступ и разместить корректную политику обработки персональных данных.
- Бесплатный тариф хостинга может засыпать при простое; первый ответ после простоя может быть медленнее.

## Структура

- `index.html` — разметка сайта
- `styles.css` — фирменный дизайн и адаптивность
- `app.js` — каталог, конструктор программы, чат и форма
- `config.js` — публичный URL backend (секретов нет)
- `main.py` — FastAPI backend и вызов GigaChat
- `requirements.txt` — зависимости Python
- `render.yaml` — blueprint развертывания Render
