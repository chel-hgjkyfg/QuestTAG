# КвестТаг — прототип сайта для GitHub Pages

Статический адаптивный прототип в фирменной палитре: чёрный, оранжевый, красный и белый. Не требует Python, Node.js, базы данных или API-ключей.

## Публикация на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите **всё содержимое этой папки** в корень репозитория (файл `index.html` должен лежать в корне).
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите `Deploy from a branch`.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. Через минуту сайт появится по адресу `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

## Что работает в прототипе

- адаптивная главная страница, каталог активностей и пакетов;
- переключение разделов прайса;
- калькулятор лазертага, Among Us, пряток и картинга с дополнительными услугами;
- демонстрационный чат-помощник с ответами на типовые вопросы из встроенного прайса;
- форма предварительной заявки с обязательным согласием;
- переход из карточек пакетов и калькулятора к форме с предварительно заполненными параметрами;
- сохранение демонстрационных заявок в `localStorage` браузера.

## Важно: ограничения GitHub Pages

GitHub Pages размещает только статические файлы. Поэтому этот вариант — работающий **клиентский прототип**, а не полная серверная версия нейроассистента из курсовой:

- чат отвечает по локальным сценариям, не подключён к GigaChat/RAG;
- заявка сохраняется только в браузере посетителя и не поступает администратору;
- нет общей базы данных, авторизации администратора, журнала обращений, Telegram-уведомлений и защищённой обработки персональных данных;
- для реального приёма заявок, панели администратора и ИИ потребуется отдельный backend/API (например, на Render, Railway или VPS), а GitHub Pages останется фронтендом.

Не используйте форму на GitHub Pages для сбора реальных персональных данных до подключения защищённого сервера и юридически корректной политики обработки ПДн.

## Цены

Прайс внесён по изображениям, приложенным к задаче: квесты, картинг, лабиринт, комнаты, дополнительные услуги и два пакетных предложения. Пакеты «Экстрим-Таг» и «Luxury» отображаются отдельно. Условия и доступность конкретной даты должны подтверждаться администратором.

## Структура

- `index.html` — страницы и интерфейс
- `styles.css` — стили и адаптивная вёрстка
- `app.js` — калькулятор, прайс, чат-демо и форма
- `assets/` — логотип и фотографии/изображения
